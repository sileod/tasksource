# jev-synthetic pilot sample

Live sample from the `deepseek_v4_flash_v1` pilot run: **3 state bundles
(9 decisions)** generated by `deepseek-v4-flash-0731` via Albert
(OpenAI-compatible), prompt `generate_v1`.

- `bundles_sample.jsonl` — canonical unit: one row per state
  (`state_id`, `state`, `questions[]` with `choice` / `noul` / `score`
  formats, plus `annotations[]` and `annotation_stats[]`).
- `flat_sample.jsonl` — one row per decision in the tasksource-jev
  training schema (`id`, `kind`, `options`, `target`, `state`,
  `question`, `source`, `variant`, `split`), retaining `state_id`,
  `question_id`, and `bundle_size` grouping info.

**Honesty note for reviewers:** the `target` distributions here are
deterministic *heuristic placeholders* (`annotator_version: jev-1.0`
echoes the pipeline config). No live Jev endpoint is wired yet —
`annotate.py` exposes the seam where the real TypeSafe/OpenJev call
goes. Do not treat these targets as model judgments.

Regenerate: `python -m tasksource.jev.synthetic.run --config
src/tasksource/jev/synthetic/configs/albert_deepseek_v4_flash.yaml
--stage all` (requires `ALBERT_API_KEY`; responses are cached by
request hash under `.synthetic_runs/`, which is git-ignored).
