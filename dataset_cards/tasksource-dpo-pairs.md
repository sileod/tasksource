# tasksource_dpo_pairs

**Preference pairs from ~470 human-annotated classification and multiple-choice tasks
of [tasksource](https://github.com/sileod/tasksource), for DPO and other preference training.**

Each pair takes one example from
[tasksource-instruct](https://huggingface.co/datasets/tasksource/tasksource-instruct).
`chosen` is the gold answer, and `rejected` is another answer the prompt offers.
No text is generated by a model: the preference comes from the source labels, notably
on NLI, logical reasoning, and other expert-built tasks.

```python
from datasets import load_dataset

ds = load_dataset("tasksource/tasksource_dpo_pairs", split="train")
ds = ds.filter(lambda use: use == "commercial", input_columns="license_use")  # optional
```

## Format

| column | content |
|---|---|
| `prompt` | the instruction, the example, and the answer options |
| `chosen` | the gold answer, formatted as the prompt asks (`entailment.`, `B.`) |
| `rejected` | another offered answer, in the same format |
| `task` | the tasksource task id |
| `license`, `license_use` | the source's licenses (see the tasksource-instruct card) |

- `rejected` is drawn uniformly from the other options, with a seed fixed per row, so
  rebuilds give the same pairs. It is a wrong answer, not necessarily a plausible one.
- Token classification and examples with a single option have no alternative answer and
  are left out.
- Tasks are interleaved round-robin. Validation and test keep up to 500 examples per task.

## Reproducibility

Built together with tasksource-instruct by
[`scripts/build_instruct_dataset.py`](https://github.com/sileod/tasksource/blob/main/scripts/build_instruct_dataset.py),
from sources at pinned Hub revisions. [sources.yaml](sources.yaml) records each task's
Hub dataset, revision, original dataset and licenses. MMLU, BIG-bench and BLiMP are left
out; other public benchmarks are in the data through their training splits.

## License and scope

The original licenses and terms of each source still apply, hence `license: other`.
`license_use` is `non-commercial` if any license found for the source is non-commercial,
`commercial` if one allows commercial use, and `unspecified` otherwise. This is a
best-effort aid, not legal advice.
